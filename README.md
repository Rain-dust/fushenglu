# 浮生录 Fu Sheng Lu

一个无依赖的移动端 PWA：简、静、纯粹，用于文学摘录与人生感悟的数字化积累本。

## 当前能力

- 素笺列表：一行一则摘录，不再使用卡片墙
- 分类只保留“摘录 / 随笔”：前者是别人的文字，后者是自己的文字
- 收敛的水墨气韵层：淡山水、梅影、竹影、兰草线、菊瓣纹
- 每日一言：多层素笺便签，可轻点撕换下一张
- 沉浸详情：默认竖排阅读，配图化为淡水墨底纹
- 落笔编辑：正文、出处、分类、字体、排版、配图
- 记录与搜索：搜索从记录页右上角进入，标记状态留在同一份记录里
- 专属印章：朱文/白文、方/长/圆、稳定纹理
- 我的：全局字体切换，覆盖文楷、宋体、黑体、仿宋、行楷、隶书、站酷、马善政、龙藏等常见中文字体方向
- localStorage 本地保存，并兼容旧 `moji.*.v1` 数据
- 详情页导出 PNG 图片

## 运行

```bash
npm start
```

打开：

```text
http://localhost:4173
```

也可以直接打开 `index.html`。

## 检查

```bash
npm run check
node qa-smoke.js
```
